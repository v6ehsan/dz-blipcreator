## 📖 Overview

**DZ-BlipCreator** is a powerful and user-friendly **in-game map management system for FiveM** that allows server developers and administrators to create, edit, customize, and manage **Blips, Markers, and Checkpoints** directly in-game without writing any code.

Designed for efficiency and flexibility, DZ-BlipCreator provides a real-time visual editing experience while keeping your map elements organized and easy to manage.

---

## ✨ Features

### 🎯 Live Preview System

Instantly preview Blips, Markers, and Checkpoints before placing them on the map.

### 🎨 Fully Customizable

* RGBA Color Support
* Scale & Size Control
* Radius Adjustment
* Heading / Rotation Control
* Precise Numeric Inputs

### 📍 In-Game Position Editing

Move preview objects using keyboard controls without physically repositioning your character.

### ✏️ Edit Existing Items

Modify existing Blips, Markers, and Checkpoints without deleting and recreating them.

### 💾 Persistent Storage

All created elements are automatically saved and restored after:

* Server Restart
* Resource Restart
* Player Reconnect

### 💻 Lua Code Export

Export created elements as ready-to-use Lua code and integrate them into other resources.

### 🔐 ACE Permission Support

```cfg
add_ace group.admin dz.blipcreator allow
```

### ⚡ Performance Optimized

Designed to provide a smooth editing experience with minimal performance impact.

## 📦 Installation

1. Download the latest release.
2. Place `dz_blipcreator` inside your server's `resources` folder.
3. Add the following to your `server.cfg`:

```cfg
ensure dz_blipcreator
```

4. Configure ACE permissions if required.
5. Restart your server.
