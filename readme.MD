## 📖 Overview

**DZ-BlipCreator** is a powerful and user-friendly **in-game map management system for FiveM**.

It allows server developers and administrators to create, edit, customize, and manage **Blips, Markers, and Checkpoints** directly in-game without writing any code.

With its real-time visual editing system, every change can be previewed instantly, making map management faster, easier, and more efficient.

> ⚡ **Create. Customize. Control.**

---

## ✨ Features

### 🎯 Live Preview System

Instantly preview **Blips, Markers, and Checkpoints** before placing them on the map.

All changes are displayed in real time.

### 🎨 Fully Customizable

Customize every important property:

* RGBA Color Support
* Scale & Size Control
* Radius Adjustment
* Heading / Rotation Control
* Precise Numeric Inputs

### 📍 In-Game Position Editing

Move preview objects using keyboard controls without physically repositioning your character.

### ✏️ Edit Existing Items

Modify previously created Blips, Markers, and Checkpoints at any time without deleting and recreating them.

### 💾 Persistent Storage

Created elements are automatically saved and restored after:

* Server Restart
* Resource Restart
* Player Reconnect

### 💻 Lua Code Export

Export created elements as **ready-to-use Lua code** and integrate them into your other FiveM resources.

### 🔐 ACE Permission Support

Control access to the editor using FiveM ACE permissions.

```cfg
add_ace group.admin dz.blipcreator allow
```

### ⚡ Performance Optimized

Built with performance in mind to provide a smooth editing experience with minimal impact on your server.

## 📦 Installation

### 1. Download

Download the latest version from the **Releases** section.

### 2. Install

Place the resource inside your server's `resources` folder:

```text
resources/
└── dz_blipcreator/
```

### 3. Add to `server.cfg`

```cfg
ensure dz_blipcreator
```

### 4. Configure Permissions

Add the required ACE permission:

```cfg
add_ace group.admin dz.blipcreator allow
```

### 5. Restart

Restart your server or start the resource:

```cfg
ensure dz_blipcreator
```
